### NETFLIX POWER BI DASHBOARD

## 📊 Data Analysis & Visualization Project

This project demonstrates end-to-end data analysis — from raw data to actionable insights — using Python and Power BI.

### 🚀 Project Overview

* Sourced real-world dataset from Kaggle
* Performed data cleaning and preprocessing to ensure data quality
* Conducted exploratory data analysis (EDA) using Python
* Created visualizations using Matplotlib to uncover trends and patterns
* Built an interactive Power BI dashboard with key insights

### 🛠️ Tech Stack

* **Python** (Pandas, Matplotlib)
* **Power BI**
* **Kaggle Dataset**

### 📈 Key Highlights

* Transformed raw data into meaningful insights
* Identified trends and patterns through visual storytelling
* Designed a user-friendly dashboard for decision-making

### 📌 Outcome

Delivered a comprehensive data analysis solution that bridges the gap between raw data and business insights through visualization and interactive reporting.
